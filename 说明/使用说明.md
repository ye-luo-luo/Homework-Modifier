## 一、系统概述

这是一套面向班级作业批改的本地工具集，共 **8 个 Python 文件**（含 `common.py` 公共模块与 `主窗口.py`/`启动.py` 统一入口，约 6000 行），配合学生目录结构与成绩登记 JSON 使用。全部文件按类型收进三个子文件夹（v3.4.0 起）：工作代码在 **`代码/`**、程序配套配置在 **`配置/`**、说明文档在 **`说明/`**。

| 文件（均在 `代码/`） | 作用 |
|---|---|
| `启动.py` / `启动.bat` | **统一启动入口（唯一入口）**。双击根目录 `启动.bat` 启动**情况监视器**；修改器/设置/框架搭建/命名器均从监控器界面内进入 |
| `情况监视器.py` | **日常入口（主界面）**。卡片式展示每个学生每讲每分类的文件情况、批改进度、反馈标记，自动处理图片（HEIC 转 JPG、缩放、规范命名） |
| `作业修改器.py` | 核心批改工具。图片批改（勾/叉/直线/文本框/评分）、联排多图、旋转、保存 `-改` 文件 |
| `作业命名器.py` | 图片规范化（HEIC→JPG、窄边缩放到不超过 1080、规范命名），支持命令行检查 |
| `框架搭建器.py` | 名单与实际文件夹的对照管理（GUI：逐项 创建文件夹/删名单条目/加入名单/删文件夹），一键修复结构 |
| `common.py` | 公共配置与工具函数（目录结构、命名规则、评分路径等），**不要修改** |
| `设置中心.py` | 修改器与监控器共用的统一设置窗口（两边可打开，含双方全部设置） |

**数据组织（v2.9.0 起程序与数据分离）**：
- **程序根目录**：本文件夹（`批改工具/`），内含 `代码/`（全部 .py）、`配置/`（`data_dir.txt`/`requirements.txt`/`名单.json`/`结构配置.json`）、`说明/`（本说明）、`启动.bat`
- **数据目录**：学生文件夹、`登记/汇报`、`视频胶囊.txt` 所在处。公开发布包的 `配置/data_dir.txt` 默认为 `.`，即数据保存在项目目录；也可改为相对/绝对路径，或用环境变量 `DSH_DATA_DIR` 覆盖。
- **data_dir.txt 写法**：支持相对程序根目录的路径（`..` 上一级、`..\数据`、`数据` 等）或绝对路径，也支持 `~` 与 `%VAR%` 展开
- 移动/迁移：**程序文件夹 + 数据目录按原相对结构整体拷贝即可**，`data_dir.txt` 无需改动（程序 = `数据目录\批改工具\` 时内容保持 `..`）

## 二、运行环境

- **Python 3.14+**（含 tkinter；本项目在 Python 3.14.7 上验证通过）
- 必备：tkinter（Python 自带）、Pillow
- 可选：`pillow-heif`（HEIC 转 JPG 需要）
- 首次部署（新机器）安装依赖：
  ```bash
  python -m pip install -r requirements.txt
  ```
  （若 `python` 不在 PATH 中，请用实际解释器的完整路径替换 `python`）

> ⚠️ 请勿使用 WorkBuddy 内置的 managed Python（无 tkinter，无法启动 GUI）。

**启动**（推荐双击根目录 `启动.bat`，或命令行进入 `代码\` 后运行；都会直接打开**情况监视器**主界面）：
```bash
cd 代码
python 启动.py        # 统一入口 → 监控器（推荐）
python 情况监视器.py  # 等价（直接运行监控器）
python 作业修改器.py  # 单独运行修改器（一般从监控器内进入）
```

## 三、快速开始

1. 双击 **启动.bat**（或进入 `代码\` 运行 `启动.py`）打开**统一主窗口**——所有工具都在这一个窗口内，
   顶部导航栏切换：📋监视器（首页）/ ✏修改器 / ⚙设置 / 🏗框架搭建器
2. 在监视器页选择讲次（如"第02讲"）与分类（作业/课前小测/错题再练）
3. 卡片显示每个学生的文件情况与批改进度；点击"打开修改器"直接切到修改器页
4. 在修改器中：左侧检索 → 单击图片打开 → 用工具批改 → `↑` 或 `w` 保存（生成 `-改` 文件）
5. **返回首页**：任意页按 `Esc`，或点导航栏「← 返回监视器」按钮
   （文本框/下拉框聚焦时 Esc 不触发返回；设置页录制快捷键时 Esc = 取消录制）
6. 各工具仍可独立运行：进入 `代码\` 直接运行 `情况监视器.py` / `作业修改器.py` 等打开独立窗口

## 四、情况监视器

### 4.1 卡片含义
- **背景色**：灰 `#f0f0f0` = 该目录无图片；浅绿 `#ccffcc` = 有已批改文件（`-改`）；浅红 `#ffcccc` = 有图片但未批改
- **文字**：学生文件夹名 + 文件数

### 4.2 顶部标记（分类反馈，常驻显色，固定 1/3 等分不遮挡名字）
- 顶部标记行**常驻显示**，始终可见——未标记时按**文件状态**显色，已标记时显示**反馈标记色**：
  - **无反馈标记**：`灰` = 该目录无文件；`红` = 有文件但存在未批改；`绿` = 全部已批改
  - **有反馈标记**：显示标记对应颜色——讲次模式三格各占 1/3：**黄 = 作业、蓝 = 课前小测、黑 = 错题再练**；考试/打卡天全宽单块：**紫 = 考试、绿 = 打卡**（标记优先，无视文件状态）
- 标记行**始终占位**——标记出现/消失不会改变卡片大小
- 操作：**在卡片上点右键**即可切换该学生当前讲次/分类的反馈标记

### 4.3 底部标记（上一讲/下一讲同类型状态）
卡片底部 8px 双色块行，左 = 上一讲、右 = 下一讲（同学生、同分类）：
- **灰** = 无文件（含越界：第 1 讲无上一讲、第 15 讲无下一讲）
- **深绿 `#2E8B57`** = 有文件且**全部已批改**
- **深红 `#D32F2F`** = 有文件但存在**未批改**
- 考试/打卡天无讲次概念，底部行自动隐藏

### 4.4 顶部工具栏
- **检索方式**：`讲次-学生`（默认，卡片=当前讲次+分类的全部学生）／`姓名-类别`（卡片=选定学生的各讲次×类别 + 考试 + 打卡）
- **姓名-类别检索**：学生面板（班级 → 序号 → 姓名）显示在检索选项栏之后；**班级/序号任意改变只刷新姓名下拉候选（组件不变）**，**选择姓名后**卡片才变为该学生 各讲次×当前分类 + 考试 + 打卡 的目录状态；**未确定学生时卡片区留空（不显示任何组件）**；拖放导入/复制批改/打开修改器均按卡片对应目录工作（打开修改器自动切换为"姓名-类别"检索，未选学生时也同步检索方式）
- **讲次下拉**：第01~15讲 / 考试 / 打卡第01~10天（考试/打卡天自动隐藏分类按钮）
- **分类单选**：作业 / 课前小测 / 错题再练
- **班级勾选**：按年份（1993/1994/…）显示/隐藏班级
- **列数**：卡片排列列数（1-10），窗口拖动自动重排
- **字体大小**：卡片文字大小

### 4.5 自动处理（每 5 秒，仅处理有变化的目录）
1. **HEIC/HEIF → JPG**（需 pillow-heif，原 HEIC 移入回收站）
2. **窄边缩放到不超过 1080**（只缩不放：小图/已优化缩略图不放大；按原始方向，不旋转）
3. **规范命名**（`年份-序号-姓名-讲次-分类-N` 格式，已规范的不动）

### 4.6 按钮功能
- **刷新**：立即重新统计（可选"当前范围/全局"，全局会清空增量缓存强制全量重扫）
- **命名**（可选"当前范围/全局"）：检查并自动修正不规范命名，无需确认（全局=全量扫描，含老图片）
- **🗜 存储优化**：设置按天数自动压缩/降质/缩略的参数，或立即优化
- **📋 复制批改**（开关）：启用后**左键点击学生卡片**，直接把该目录中的 `-改` 图片路径和说明文字写入剪贴板，**不创建重复图片副本**。复制内容可在设置中心调整：
  - 可选：**讲次信息**、**类型信息**、**胶囊视频**、**图片** 四类内容
  - **讲次 / 考试 / 打卡 分开设置、互不影响**（各自独立记忆勾选状态）
  - 未勾选「图片」时剪贴板仅复制文字
  - 完整文字模板可修改，默认：`{class}班 {seq}号 {name}的{lecture}的{sub}{capsule}`；例如 `2024班 01号 张三的第02讲的作业，《胶囊名》 https://example.com/video（视频胶囊）`
  - 可选额外保存「情况说明.txt」到汇报目录；默认关闭
  **剪贴板两种模式，连续点击同一卡片交替**（微信/QQ 一次粘贴只消费一种格式；勾选「图片」时生效）：
  - **第一次点击 = 图片模式**：剪贴板写入 **QQ 图文同贴的完整格式组合**（逆向自真实 QQ 复制样本）——`QQ_Unicode_RichEdit_Format`（QQ 私有图文格式，QQ 粘贴图文同现）+ HTML Format + 纯文本 + 图片文件列表（微信发图兜底）
  - **再次点击同一卡片 = 文字模式**：剪贴板仅含说明文本（纯文字），微信/QQ 中 Ctrl+V **粘贴即文字消息**
  - 弹幕会提示当前模式与切换方式；点击其他卡片自动回到图片模式。停用时左键恢复为打开文件夹。
- **✏ 打开修改器**：启动批改工具（自动携带当前检索范围）
- **🗑 删除**（开关，与复制批改互斥）：启用后**左键点击学生卡片** = 打开「删除图片」对话框，列出该学生当前讲次/分类文件夹里的**所有图片**（含 `-改`、无扩展名的微信/QQ 临时图；最新放入的排前面）——多选后**移入回收站（可恢复）**。用于删除**放错的图片**：既包括"之前放错、后来发现的"，也包括"上一步刚拖放放入的错图"。删除前有确认弹窗，删除走回收站（双保险，可找回）。
- **反馈方式**：除「名单与文件夹不符」选择窗口与**删除确认弹窗**外，监视器**无弹窗**——所有提示（复制完成、命名结果、存储优化、文件夹清理等）以**顶部弹幕**显示（3 秒自动消失，最多 3 条）

### 4.7 拖放导入（外部图片 → 学生文件夹）
- 把**电脑里的图片文件**直接拖到某位学生的卡片上 → 图片自动复制到该学生当前讲次/分类的文件夹（考试/打卡天复制到对应目录）
- 支持常见图片格式 + **HEIC/HEIF**（复制后自动转 JPG）；**微信/QQ 拖出的无扩展名临时文件**也能识别（按内容探测，自动补扩展名）
- 重名文件自动加 `(1)(2)` 后缀，不覆盖；复制完成后自动触发该目录处理（缩放 1080 + 规范命名）
- 反馈以**弹幕**显示（复制张数 + 目标目录），不弹窗打断操作
- 依赖 `tkinterdnd2`（未安装时拖放不可用，程序其余功能正常）

## 五、作业修改器

### 5.1 左侧检索栏
- **检索方式（第一项）**：`讲次-学生`（讲次/分类/班级/序号）／`姓名-类别`（班级 → 序号 → 姓名逐级定位；班级+序号唯一时自动选中姓名；选学生 → 该学生各讲次×类别 + 考试 + 打卡；考试和打卡在任何类别下都包含；班级/序号仅用于快速定位姓名，两种检索独立、共用同一修改器）；切换检索方式即时生效
- **姓名-类别交互**：班级/序号任意改变只刷新姓名候选（列表不变），选择姓名后列表才变为该学生各讲次×类别 + 考试 + 打卡；未选姓名时列表留空（无提示项）
- **筛选自动换行**：紧跟在检索方式之后，开启时分类/班级选项多行显示完整
- **筛选**：讲次 / 分类 / 班级 / 序号 / 状态（全部/未批改/已批改）
- **序号下拉自动识别**：选项 = 当前讲次+分类+班级范围内的实际图片序号（切换范围后自动更新；选中序号不在新范围时自动重置为"全部"）
- **未批改标红**：检索列表中未批改（无 `-改`）的条目显示红色
- **检索**：应用筛选条件；保存/刷新后自动重新检索

### 5.2 批改工具（右侧工具面板）
| 工具 | 说明 |
|---|---|
| ✅ 勾 | 点击画布添加（红色，宽 3px） |
| ❌ 叉 | 同上 |
| ➖ 直线 | 拖拽两点绘制（红色，宽 3px，可在设置中加粗） |
| 📝 文本框 | 点击创建后**画布内嵌编辑**（双击已建文本框可再次编辑；支持换行/对齐/填充色） |
| 评分 | 按分类显示快捷分：作业=自定义文本；课前小测/打卡=0-10 快捷按钮；考试=0-100 输入框（越界弹幕提示） |

### 5.3 联排模式（Ctrl+T）
- 一个文件夹 = 一组，多图无缝拼接平铺
- **点击某张图**切换当前编辑图（蓝色高亮框）
- **旋转图片（顺时针）**：只旋转当前选中的那张图，标注坐标同步变换；其他图不受影响
- 切组/切回：未保存的标注与旋转状态自动暂存恢复
- **保存**：把每张有标注的图合成各自的 `-改` 文件（含切组暂存的其他组）；退出联排时自动保存
- 切组时未保存内容存入暂存，组内显示 原图 / -改 自动切换

### 5.4 保存与文件
- 保存后生成 `-改` 文件（如 `…-作业-1.jpg` → `…-作业-1-改.jpg`），**原图保留**；再次批改保存会更新 `-改`
- 保存后检索栏该图红标自动消除（转为已批改）

### 5.5 快捷键（可在 设置→快捷键 中自定义）
| 按键 | 功能 |
|---|---|
| `←` / `→` | 上一张 / 下一张（联排模式 = 上一组 / 下一组） |
| `↑` | 保存 |
| `Ctrl+T` | 开关联排模式 |
| `PgUp` / `PgDn` | 切图 / 切组 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（联排下精确作用于对应图片） |
| `Delete` | 删除选中元素 |

**自定义快捷键**：设置→快捷键中点击"设置"后按任意键（**键盘全部键含无修饰单字符键** + 鼠标键/**侧键（XButton1/2）**/滚轮/双击 + Ctrl/Shift/Alt 组合）即可录制。
- **冲突拒绝**：与固定功能（切图/撤销/重做/删除元素）或其他已配置快捷键相同的键会被拒绝并提示，请换一个
- **输入防冲突**：在文本框输入/左栏筛选/右栏输入时快捷键自动屏蔽；**中文输入法开启时裸字符键自动屏蔽**（避免输入法候选框与快捷键冲突），组合键（Ctrl+Z 等）照常；Esc 取消录制

### 5.8 设置中心（统一设置）
修改器「⚙ 设置」与监控器「⚙ 设置」打开**同一个设置窗口**，包含双方全部设置：
- **监控器页**：卡片字体/列数、弹幕时长、自动处理间隔（秒）、存储优化（启用/各分级天数/缩略边长）、复制批改内容（讲次/考试/打卡 分开勾选：讲次信息、类型信息、胶囊视频、图片；默认全选）
- **修改器页**：弹幕时长、绘图工具（颜色/线宽）、文本框（内容/字体/字号/颜色）、评分（字体/字号/颜色）、联排（列数/间距/标签/最大张数/填充）、快捷键（任意键录制+冲突检测）
- **目录结构页**：讲次/考试/打卡顺序，以及讲次分类的添加、修改、删除和排序。新增分类会补齐现有目录；修改分类会同步迁移目录、标准文件名和评分；删除分类会归档到数据根的 `_待清理`。含文件的分类改名或删除前会显示影响数量并要求确认。
- 保存时会校验数值范围、存储优化阶段顺序、颜色、填充模式、快捷键冲突和分类名称；保存后重新进入相关页面即可使用新设置。
| `双击元素` | 编辑文本框 |

### 5.6 弹幕与弹窗
- **除删除源文件外，全程无弹窗**——所有反馈（保存成功、评分越界、提示等）以顶部弹幕显示
- **删除源文件**：唯一的确认弹窗（彻底删除 `-改` 外的源文件，删除后自动跳转下一张）

### 5.7 设置
- 工具颜色/线宽、文本框字号、评分字号颜色
- **预设**：为当前工具保存/删除命名样式（删除预设 = 删除当前激活的预设，无需输入名称）
- 快捷键自定义

## 七、框架搭建器

- **GUI 模式（默认）**：`python 框架搭建器.py` 打开「名单与文件夹对照」窗口。
  扫描后分两栏展示不符项，**逐项多选（Ctrl/Shift 点击），自由选择处理方式**：
  - 【名单有 · 磁盘无】→ ① 创建文件夹（含完整讲次/子类型/考试/打卡结构） ② 删除名单条目（仅改 名单.json，不删磁盘）

  - 格式不符文件夹不自动处理，仅在状态栏提示（安全起见请手动确认）
- 情况监视器检测到名单与实际文件夹不符时，弹窗提供「打开框架搭建器（逐项全面处理）」入口，可直接跳转逐项处理
- **命令行模式（保留）**：`python 框架搭建器.py --cli`
  - 一键创建/修复全部学生目录结构；清理空的不合规/多余文件夹（移入回收站）；报告名单差异
  - 模块化调用（`build_structure()` / `check_student_folders()` / `check_sub_folders()` / `ensure_student_folder()`）

## 八、数据与文件结构

### 8.1 目录结构（v3.4.1 起 程序分 代码/配置/说明 三个子文件夹 + 数据分离，程序配置全部收进 配置/）
```
程序目录（批改工具/，本文件夹）
├── 启动.bat                 # Windows 双击入口（GBK 编码；调用 代码\启动.py）
└── 代码/                    # 工作代码（全部 .py 集中于此）
    ├── 启动.py              # 统一启动入口（唯一入口，启动即监控器）
    ├── 主窗口.py / 情况监视器.py / 作业修改器.py / 设置中心.py / 框架搭建器.py / 作业命名器.py / common.py
└── 配置/                    # 程序配套配置（v3.4.1 起 名单/结构/修改器/监控器/存储优化 等配置统一收进这里）
    ├── data_dir.txt         # 数据目录路径（公开发布包默认 `.`=项目目录）
    ├── requirements.txt     # 依赖清单
    ├── 名单.json            # 学生名单（权威且唯一：v3.4.2 起完全由本配置决定，代码不内置/不兜底；
    │                        #   缺失/为空 = 空名单，新环境经监控器"添加文件"或框架搭建器从磁盘重建）
    ├── 结构配置.json        # 目录结构配置（讲次/考试/打卡顺序与次数、讲次下子类型；缺失走默认）
    ├── image_tool_config.json       # 修改器配置（工具样式/快捷键/预设/布局）
    ├── .file_monitor_settings.json  # 监控器设置（讲次/列数/反馈标记/隐藏班级）
    └── _storage_opt.json    # 存储优化状态（图片压缩/降质/缩略的已处理级别记录）
└── 说明/                    # 使用说明

数据目录（BASE_DIR，见 配置/data_dir.txt，本套件为 <数据目录>）
├── 2024-01-张三/ … 各学生文件夹
│   ├── 第01讲/{作业,课前小测,错题再练} … 第15讲/…
│   ├── 考试/
│   └── 打卡第01天/ … 打卡第10天/
├── 登记/                     # 成绩登记（评分 JSON，原子写入防损坏）
│   ├── 第1讲.json … 第15讲.json
│   ├── 考试.json
│   └── 打卡01天.json …
├── 登记/汇报/                # 可选保存情况说明.txt；不保存重复图片副本
├── 视频胶囊.txt               # 视频胶囊库（情况说明文本自动引用；格式见 4.6 节）
└── .workbuddy/               # 进程锁/检索状态等（自动维护）
```

> **程序/数据分离说明**：数据目录由 `配置/data_dir.txt` 指定。公开发布包默认使用 `.`（项目目录）；如需程序与数据分离，可改为其他相对路径或绝对路径，也可用环境变量 `DSH_DATA_DIR` 覆盖。
> v3.4.0 起工作代码全部收进 `代码/`、配套配置收进 `配置/`、文档收进 `说明/`；v3.4.1 起 **名单.json/结构配置.json/修改器配置/监控器设置/存储优化状态 等程序配置也从数据根收进 `配置/`**（代码经 `config_file_path` 统一解析：优先配置目录，旧位置有同名文件时自动回退读取，兼容旧部署）；「批改工具」文件夹本身属于合规文件夹（加入合规名单，不再被格式检查误报/清理）。
> **v3.4.2 名单规则**：**py 代码不存储任何学生信息（含默认名单）**，名单完全由 `配置/名单.json` 决定——缺失/为空 = 空名单（出厂不再预置 88 人）。所有需要文件地址的地方一律用相对路径（检索状态等存相对 BASE_DIR，`data_dir.txt` 为相对路径），**整体拷贝程序 + 数据目录即可迁移**；到新环境时可**抛弃旧配置**（不拷贝 `配置/` 或清空名单），首次启动监控器检测到磁盘有学生文件夹而名单为空时会弹窗「添加文件」，一键把磁盘学生文件夹加入名单重建名单。
>
> **名单管理**：名单仅存于 `配置/名单.json`；监控器启动检测到名单与磁盘不符时会弹窗，三选一：
> **添加文件** = 把磁盘上名单外的学生文件夹加入名单；**删除名单** = 移除名单中磁盘上不存在的学生；**暂时不管** = 本次跳过（下次启动再提示）。
> 处理结果写入 `名单.json`（配置目录，此后以此为准），也可直接编辑该文件手动增删学生（格式：`{"年份": [[序号, "姓名"], ...]}`）。

### 8.2 命名规范
图片文件名：`年份-序号-姓名-讲次-分类-序号.jpg`，批改后追加 `-改`（如 `…-作业-1-改.jpg`）。

### 8.3 数据安全
- 数据读写基于 `BASE_DIR`（数据根目录，由 `配置/data_dir.txt` 指定）；程序配置读写 `配置/`（`config_file_path` 统一解析），**无任何绝对路径写入**
- 配置/评分写文件采用**原子写**（临时文件 + 替换），中途崩溃不损坏数据
- 拷贝程序（`批改工具/` 含 代码/配置/说明）到别处运行 = 全新数据根，**原位置成绩登记零影响**

## 十、常见问题与注意事项

1. **为什么图片不自动转正？** 所有自动旋转/摆正已取消（含 EXIF），图片按拍摄原始方向显示——如需调整用修改器"旋转图片"按钮手动旋转后保存。
2. **打卡目录为什么是空的？** 打卡第01~10天目录为框架预建的空目录，属正常，打卡开始后自动填充。
3. **监控器卡片顶部的窄色条是什么？** 常驻的分类标记行——未标记时按该分类目录文件状态显色（灰/红/绿），标记后显示标记对应颜色（黄/蓝/黑/紫/绿），始终可见、不改变卡片大小。
4. **同时打开监控器与修改器**：正常使用无冲突（文件均已规范命名时监控器不会自动改名）；请勿在两个窗口同时编辑同一张图片。
5. **成绩登记在哪？** 数据根 `登记/*.json`，随数据目录移动；评分后自动保存（原子写，防损坏）。
6. **换电脑/迁移**：程序文件夹（`批改工具/`，含 代码/配置/说明）+ 数据目录按原相对结构整体拷贝即可（程序 = `数据目录\批改工具\` 时 `配置/data_dir.txt` 保持 `..` 不用改）；若结构变化，改 `配置/data_dir.txt` 为对应的相对/绝对路径，或用 `DSH_DATA_DIR` 环境变量指定。
7. **空文件夹会自动清理吗？** 启动时检测到空的、不合规/多余的文件夹会**自动移入回收站**（可恢复）并弹幕提示，不再弹窗确认；含文件的文件夹仅提示，请手动处理。
8. **视频胶囊.txt 怎么维护？** 每个胶囊 2 行（`【知识胶囊】…《胶囊名》` + 链接），每讲次一组（作业/课前小测/错题再练），讲次之间空一行。程序自动识别胶囊名中的讲次与分类（支持 `新高一第一讲作业`、`第五讲作业`、`作业9`、`第十三讲错题再练` 等写法）。打卡胶囊暂无，后续补充后（如 `这是第02天的打卡，xxx`）会自动生效。
