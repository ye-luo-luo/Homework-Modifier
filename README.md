# Homework-Modifier
A Windows desktop tool designed for collecting, checking, and image grading of class assignments. The project is built using Python, Tkinter, and Pillow, integrating situation monitoring, image grading, file naming, roster management, and directory maintenance into a single window, with all student data saved locally.
# 批改工具

一套面向班级作业收集、检查与图片批改的 Windows 桌面工具。项目使用 Python、Tkinter 和 Pillow 构建，将情况监视、图片批改、文件命名、名单管理和目录维护整合到同一个窗口中，所有学生数据均保存在本地。

> 当前版本：v3.4.3  
> 运行环境：Windows 10/11、Python 3.14+

## 主要功能

- **情况监视器**：按讲次、分类和班级展示学生提交数量及批改状态。
- **图片批改**：支持勾、叉、直线、文本框、评分、旋转、撤销/重做和多图联排。
- **自动整理图片**：支持 HEIC/HEIF 转 JPG、图片缩放和标准文件名整理。
- **动态目录结构**：可配置讲次、考试、打卡和讲次分类；分类新增、改名、删除会同步处理目录、文件名和评分数据。
- **名单与文件夹管理**：维护班级、学号、姓名和学生学习讲次，并检查名单与磁盘目录是否一致。
- **复制批改结果**：直接将原始 `-改` 图片路径和可配置说明文字写入剪贴板，不创建重复的汇报图片副本。
- **本地数据管理**：配置、名单、评分和图片均保存在本机，不依赖云端服务。
- **存储优化**：可按图片存放天数执行压缩、降质或缩略处理。

## 界面组成

统一主窗口包含四个页面：

| 页面 | 用途 |
|---|---|
| 情况监视器 | 查看每位学生的提交和批改状态，拖放导入图片，复制批改结果 |
| 作业修改器 | 打开图片并完成标注、评分、联排和保存 |
| 设置中心 | 调整监视器、修改器、快捷键、目录结构、复制文字和学生名单 |
| 框架搭建器 | 对照名单与实际文件夹，创建缺失目录并处理不一致项 |

## 快速开始

### 1. 准备 Python

安装 Python 3.14 或更高版本，并确保安装时包含 Tkinter。

请使用系统 Python。某些不带 Tkinter 的精简或托管 Python 环境无法启动桌面界面。

### 2. 安装依赖

在项目根目录执行：

```powershell
python -m pip install -r 配置/requirements.txt
```

依赖说明：

- `Pillow`：图片读取、缩放和标注合成，必需。
- `pillow-heif`：HEIC/HEIF 转换，可选。
- `tkinterdnd2`：从资源管理器拖放图片，可选。

### 3. 启动程序

推荐直接双击：

```text
启动.bat
```

也可以通过命令行启动：

```powershell
python 代码/启动.py
```

启动后默认进入情况监视器，可通过顶部导航切换其他页面。

## 基本工作流

1. 在设置中心维护班级、学生、讲次和分类。
2. 使用框架搭建器创建或检查学生目录结构。
3. 在情况监视器选择讲次和分类，查看学生提交状态。
4. 将图片拖入学生卡片，或把图片直接放入对应学生目录。
5. 进入作业修改器完成批注和评分，保存后生成带 `-改` 后缀的结果图。
6. 开启“复制批改”后点击学生卡片，将批改图和说明文字放入剪贴板。

## 复制批改文字

默认模板：

```text
{class}班 {seq}号 {name}的{lecture}的{sub}{capsule}
```

示例输出：

```text
2024班 01号 张三的第06讲的作业，《第六讲作业》 https://example.com/video（视频胶囊）
```

可用字段：

| 字段 | 内容 |
|---|---|
| `{class}` / `{class_name}` | 班级 |
| `{seq}` | 学号 |
| `{name}` | 姓名 |
| `{lecture}` | 讲次、考试或打卡日 |
| `{sub}` | 作业分类 |
| `{capsule}` | 匹配到的视频胶囊名称和链接；无匹配时为空 |

模板可在“设置中心 → 监控器 → 复制文字模板”中修改。图片直接使用原始批改文件路径写入剪贴板，不会复制到中间目录。可选开启“额外保存情况说明.txt”。

## 数据目录

程序文件与学生数据可以分离存放。数据目录由以下方式确定，优先级从高到低：

1. 环境变量 `DSH_DATA_DIR`。
2. `配置/data_dir.txt` 中记录的相对或绝对路径。
3. 未配置时使用程序根目录。

公开发布包的 `配置/data_dir.txt` 默认值为 `.`，学生数据会保存在克隆后的项目目录中。需要把数据单独存放时，再将其改成其他相对路径或绝对路径。

`data_dir.txt` 支持：

- 相对路径，例如 `..`、`../数据`；
- 绝对路径；
- `~` 和 `%ENV_VAR%` 环境变量展开。

典型数据结构：

```text
数据目录/
├─ 2024-01-张三/
│  ├─ 第01讲/
│  │  ├─ 作业/
│  │  ├─ 课前小测/
│  │  └─ 错题再练/
│  ├─ 考试/
│  └─ 打卡第01天/
├─ 登记/
├─ 视频胶囊.txt
└─ 批改工具/
   ├─ 代码/
   ├─ 配置/
   ├─ 说明/
   └─ 启动.bat
```

讲次、考试、打卡和分类均可在设置中心调整，因此实际目录可能不同。

## 文件命名

讲次图片采用以下标准格式：

```text
班级-学号-姓名-讲次-分类-序号.jpg
班级-学号-姓名-讲次-分类-序号-改.jpg
```

考试和打卡文件不包含讲次分类字段。程序会尽量自动规范文件名，并保留原图与 `-改` 文件的对应关系。

## 数据安全

- 分类中存在文件时，改名或删除前会显示影响范围并要求确认。
- 分类删除不会直接永久清除数据，而是归档到数据目录下的 `_待清理`。
- 文件夹清理和图片删除优先使用可恢复方式。
- 存储优化中的降质和缩略不可逆，执行前应确认参数并保留必要备份。
- 建议定期备份学生数据目录、`配置/名单.json` 和 `登记/`。

## 注意事项

- 项目目前主要面向 Windows，剪贴板图文格式、批处理启动和部分文件操作依赖 Windows 行为。
- 首次使用前建议先配置数据目录和名单，再运行框架搭建器检查目录。
- 不要在程序处理图片时同时手工批量移动同一批文件。
- 修改目录结构前请关闭其他可能操作学生目录的程序。

更完整的操作说明见 [`说明/使用说明.md`](说明/使用说明.md)。
